
# AirPulse — Hyperlocal Air Pollution Forecasting

AirPulse is a university MLOps project focused on hyperlocal air pollution forecasting.

The project aims to build an end-to-end machine learning pipeline that analyzes air quality data, predicts future pollution levels, and makes forecasts accessible through an interactive application.

## Project Objectives

- Analyze historical air quality data.
- Develop machine learning models for pollution forecasting.
- Build an end-to-end MLOps pipeline.
- Containerize the application using Docker.
- Provide an interactive interface for exploring predictions.
